Swipe your way to your next favourite meal. A native Android culinary companion with an adaptive swipe engine, a Capture Fridge pantry auditor and a Smart Grocery Aggregator - powered by a custom REST API on Supabase.

View the repository Setup guide

What ships in Part 2

Google SSO + Email auth Credential Manager sign-in; the auth-sso Edge Function exchanges the Google ID token for a server-issued session JWT (FR-01).
Adaptive Swipe Deck Ranked card stack; every gesture moves tag points in user_taste_profiles and re-ranks the next deck (FR-06..12).
Capture Fridge Pantry with expiry alerts, quick-add cloud and a match algorithm returning % + missing ingredients (FR-17..20).
Smart Grocery Aggregator Right-swipes auto-fill an aisle-grouped basket minus pantry stock, with checkable items and sharing (FR-21..24).
Settings that persist Dietary filters, language, theme, notifications and taste-profile reset - all round-tripped through the API (FR-25..27).
CI + 33 unit tests GitHub Actions builds the APK and runs the full JUnit suite on every push.

Quick start

  1. Create a free Supabase project; run supabase/migrations/0001_forkful_init.sql then supabase/seed.sql in the SQL editor.
  2. Deploy the ten Edge Functions from supabase/functions/.
  3. Create a Google Cloud Web OAuth client and enable the Google provider in Supabase Auth.
  4. Paste your URL, anon key and client ID into app/build.gradle.kts.
  5. Open in Android Studio → Run on a physical device.

The full walkthrough with PowerShell commands lives in SETUP.md.
